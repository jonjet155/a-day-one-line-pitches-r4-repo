One sentence, 193 characters, that would convince a friend who has never
coded to let an AI agent build their first app idea on make.fun.

> You've already got the idea — say it out loud to make.fun in plain words, and an AI agent builds a first version you can actually use by morning, no code, and you only pay for the one you keep.

## How it works

`main.py` (Python standard library only) writes that exact sentence to
`/output/entry.txt` (UTF-8, 1–240 characters).

Run it locally:

```sh
python3 main.py
```
